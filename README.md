# Starfighter: The Void Vanguard (星海先锋)

## 项目简介
这是一个基于 C++ 和 Raylib 图形库开发的高性能 2D 弹幕射击游戏 (Space Shooter)。
本项目旨在展示 C++ 面向对象编程、内存管理 (对象池) 以及基础的图形学应用。

## 核心技术
- **语言**: C++ 14
- **引擎**: Raylib
- **架构**: 实体组件系统 (Entity System), 对象池 (Object Pool)
